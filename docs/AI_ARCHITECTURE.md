# AI Architecture

## Principles
- Keep business logic modular and testable.
- Separate orchestration from domain implementation.
- Prefer explicit contracts for services and data flows.

## Suggested Structure
- Components for UI composition.
- Features for domain-specific modules.
- Services for external integrations and orchestration.
- Hooks for shared client-side behavior.
- Utilities and types for reusable abstractions.

## Integration Notes
AI-assisted workflows should rely on clear interfaces, documented data contracts, and maintainable module boundaries.
